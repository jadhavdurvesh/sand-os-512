# 10 — Memory and numerical capabilities

A 512-bit scalar contains 2^512 possible patterns. Its unsigned range is 0 through 2^512−1; signed two's-complement range is −2^511 through 2^511−1. It needs up to 155 decimal digits or 128 hexadecimal digits.

If all 512 bits were used for byte addressing, the mathematical space would be 2^512 bytes. This is not installed RAM, physical capacity, or a recommended address width.

Keep distinct: scalar value capacity, virtual address space, physical address space, installed RAM, storage capacity, and memory bandwidth.

Actual capacity depends on implemented address bits, memory devices, buses, controllers, translation structures, and platform design. Publish implemented limits and measured results; do not present theoretical bit counts as hardware capability.
